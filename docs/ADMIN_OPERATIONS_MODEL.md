# Safa Foods Admin Operations Model

## 1. Daily Admin Tasks

- review new orders
- confirm payment or COD eligibility
- monitor subscription deliveries for the day
- update order status
- check customer WhatsApp issues
- update out-of-stock products
- publish daily offer banners if needed

## 2. Store Operator Dashboard

Should show:

- today’s one-time orders
- today’s subscription deliveries
- pending confirmations
- preparing orders
- out-for-delivery orders
- failed or skipped deliveries

## 3. Content Dashboard

Should show:

- homepage banners
- active offers
- blog drafts
- FAQs
- category content

## 4. Delivery Dashboard

Should show:

- orders by zone
- delivery addresses
- status buckets
- estimated delivery windows

## 5. Subscription Dashboard

Should show:

- active subscriptions
- paused subscriptions
- renewals due
- today’s subscription deliveries
- failed subscription deliveries
