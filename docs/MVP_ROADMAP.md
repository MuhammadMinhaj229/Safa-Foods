# Safa Foods MVP Roadmap

## Phase 0: Business Decisions

Lock before development:

- exact product list
- pack sizes
- prices
- subscription frequency options
- delivery zones
- delivery charges per zone
- COD eligibility rules
- cancellation / refund rules
- order fulfillment flow
- subscription renewal model
- notification channel rules

## Phase 1: UX and Brand System

Deliverables:

- sitemap
- wireframes
- design system
- homepage sections
- product page layout
- checkout flow
- account flow

## Phase 2: Core Build

Deliverables:

- Next.js storefront
- Shopify setup
- Sanity content model
- Razorpay integration
- account area
- order status flow
- delivery-charge logic
- SEO setup

## Phase 3: Launch Readiness

Deliverables:

- test orders
- subscription test flows
- COD tests
- mobile QA
- performance QA
- analytics setup
- WhatsApp integration
- legal pages

## Phase 4: Growth

Post-launch additions:

- offers engine
- referral codes
- Instagram feed integration
- customer reviews
- recipe blog growth
- abandoned cart flows
- delivery dashboard
- reseller / bulk orders
